# G.L. Bajaj Online Book Store

The homepage, login, registration, catalogue and cart implement the BCS353 Web Designing Workshop bookstore. Open `index.html` to start.

The bookstore uses the GL Bajaj orange/cream design, PDF catalogue covers for XMLBible, AI and Java 2, and the selected CSE/ECE/EEE book entries. The EEE item is Basic Electrical Engineering by D. P. Kothari and I. J. Nagrath (McGraw Hill, MRP ₹925). Cart contents use browser local storage; login and checkout are front-end demonstrations.
